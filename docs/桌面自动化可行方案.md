# 桌面自动化可行方案

> 日期：2026-07-13

---

## 一、为什么不可能成功

通用 VLM（Qwen-VL-Max）被强行塞进循环里：

```
真实 GUI Agent: 视觉+行动在同一训练目标优化，会从反馈学习
我们的方案:     每步独立看图→独立猜→不知道上一步是否成功
```

**换 prompt/加 OCR/换匹配算法都修不了——模型不是 Agent，不是设计来干这个的。**

---

## 二、方案 A：Qwen3.7-Plus API（最快）

### 为什么

Qwen3.7-Plus 是专门用强化学习在桌面操作轨迹上训练的 GUI Agent。ScreenSpot Pro 79.0（我们的 Qwen-VL-Max: ~30）。

### 第一步：验证 API（5 分钟）

```python
from openai import OpenAI
c = OpenAI(api_key="你的key", base_url="https://dashscope.aliyuncs.com/compatible-mode/v1")
r = c.chat.completions.create(model="qwen3.7-plus", messages=[{"role":"user","content":"回复OK"}])
print(r.choices[0].message.content)
```

### 第二步（30 分钟）

删掉 OmniParser/OCR/所有中间层。截图→base64→Qwen3.7-Plus→`click(350,420)`→执行。

### 风险

API 可能不支持图片输入。北京端点可能不稳。
