## 一、项目定位

数字鹰红叶是一个 **AI 数字生命** 项目，运行在 Windows 上。目标是构建一个有记忆、能看屏幕、能操作桌面、有个性的 AI 代理。

四个核心维度：

| 维度 | 模块 | 技术栈 |
|------|------|--------|
| **记忆** | 长期记忆 + 知识图谱 | Neo4j + Graphiti |
| **视觉** | 屏幕理解 + 元素定位 | OmniParser V2 (YOLO + Florence-2) + Qwen-VL |
| **行动** | 桌面操作 + 浏览器控制 | pyautogui + Chrome Extension(chrome.debugger) |
| **人格** | RAG 对话 + 角色扮演 | DeepSeek v4 Pro |

重要区分：视觉模块负责**屏幕截图理解**——包括桌面应用、资源管理器、游戏、摄像头画面等一切非浏览器场景。浏览器内的操作走 CDP（扩展直接注入 JS 查 DOM），因为 CDP 比视觉更快更准。视觉模块只在 CDP 不可用时启用。

## 四、Agent 决策流程

```
用户输入 goal
    ↓
DeepSeek: 决定下一步 {action, target}
    ↓
┌─ CDP 已连接？ ──────────────────────────┐
│ YES:                                    │ NO:
│   navigate → 扩展 chrome.tabs.update     │   视觉管线
│   type     → 扩展 Input.dispatchKeyEvent │   OmniParser → Qwen → pyautogui
│   press    → 扩展 Input.dispatchKeyEvent │
│   click    → 扩展 find_element JS → 坐标 │
│              → Input.dispatchMouseEvent  │
└──────────────────────────────────────────┘
    ↓
执行 → 截图验证 → 因果追踪(下一步期望)
    ↓
循环直到 done 或 max_steps
```

**关键原则**：CDP 模式下 click 只用 DOM 查询，找不到元素直接 ask 用户，不走视觉 fallback。视觉模块只用于非浏览器场景（资源管理器、游戏、桌面应用等）。

## 五、启动方式

### 1. Chrome 扩展（一次性）

chrome://extensions/ → 开发者模式 ON → 加载已解压 → 选 `extension/` 目录

### 2. 守护进程

```bash
cd F:\PSet\DigitalEagleRedLeaves
set PYTHONPATH=src
.venv\Scripts\python.exe -m agent.daemon
```

看到 `[IPC] http://127.0.0.1:9020` 即就绪。

### 3. 发任务

```bash
.venv\Scripts\python.exe -m agent.cli "打开Chrome进入网页版B站搜索推理视频，选第一个看"
.venv\Scripts\python.exe -m agent.cli --status
.venv\Scripts\python.exe -m agent.cli --cancel
```

### 4. 老版 Agent（不用 daemon）

```bash
python scripts/agent_demo_layered.py
```

## 六、Chrome CDP 方案演进的教训

| 方案 | 结果 | 死因 |
|------|------|------|
| `--remote-debugging-port=9222` 默认Profile | ❌ | Chrome 136+ 静默忽略 |
| 目录联结 + `--user-data-dir` | ❌ 数据损坏 | 路径变了 → DPAPI 密钥轮换 → 全部 Cookie 丢失 |
| `chrome://inspect` 模式 | ❌ | 弹窗 + 连接限流 + Page 级命令路由不通 |
| Playwright `launch_persistent_context` + 默认Profile | ❌ | `--disable-features=DevToolsDebuggingRestrictions` 在 Chrome 150 已移除 |
| **Chrome 扩展 + chrome.debugger** | ✅ | 零侵入，用户 Chrome 原样跑 |

详细事故报告：`docs/postmortem-chrome-profile-corruption.md`
