## 七、★ 07-12 新增：LLM 后端切换功能

### 改动文件

| 文件 | 变更 |
|------|------|
| `src/core/config.py` | 新增 `LLM_BACKEND` 开关 + `resolve_*()` 方法 |
| `src/core/brain_engine.py` | LLM 改用 `resolve_*()`，Embedding/Reranker 固定走 Ollama |
| `src/core/personality.py` | 改用 `Config.resolve_model()` |

### 使用方式

**只需改 `config.py` 一个变量：**

```python
LLM_BACKEND = "deepseek"   # DeepSeek API（云端）
LLM_BACKEND = "ollama"     # 本地 Ollama
```

其他代码无需任何改动。`resolve_base_url()`、`resolve_api_key()`、`resolve_model()` 三个方法自动根据 `LLM_BACKEND` 返回值。

### 重要说明

- LLM 可在 DeepSeek / Ollama 之间自由切换
- Embedding 和 Reranker **始终**走本地 Ollama（DeepSeek 不提供这些 API）
- 用 DeepSeek 前需将 `DEEPSEEK_API_KEY` 换为真实 key

### 启动方式

```bash
# 启动聊天（大脑 + 人格）
python -m src.core.chat

# 启动视觉服务
python src/vision/vision_server.py

# 启动系统监控
python src/tools/monitor.py

# 批量导入记忆
python scripts/ingestMemory.py
```
