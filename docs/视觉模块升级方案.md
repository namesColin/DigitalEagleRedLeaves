## 一、现状诊断

### 1.1 当前架构

```
pyautogui 截屏 → FastAPI HTTP → Florence-2-large (0.7B) → JSON 返回坐标+标签
```

### 1.2 发现并修复的问题

**问题一：推理极慢** — 原始 `<OCR_WITH_REGION>` 耗时 672s（11 分钟）。

根因：

| 参数 | 改前 | 影响 |
|------|------|------|
| `num_beams` | 3 | 3 条并行搜索，每 token 3 次 forward |
| `max_new_tokens` | 1024 | 生成上限过高 |
| `use_cache` | False | 禁用 KV-cache（Florence-2 代码 bug，必须保持 False） |

修复后：

| prompt | 修复前 | 修复后 |
|--------|--------|--------|
| OCR | 672s | 4.02s |
| OD | 3.57s | 0.26s |
| Caption | 崩溃 | 0.61s |

**问题二：坐标双重转换** — `post_process_generation(image_size=...)` 已转像素，debug_view 又乘一遍。

**问题三：27 框重叠** — 添加 IoU 去重。

**问题四：标签乱码** — 清洗 `</s>` `<s>` token。

### 1.3 Florence-2 根本局限

非 UI 专用模型，标签无意义（"x" 而非 "close button"），无 NMS，无空间关系。

## 三、OmniParser V2 调研详情

### 3.1 内部结构

OmniParser V2 不是 pip 包，是微软的开源项目 ([github.com/microsoft/OmniParser](https://github.com/microsoft/OmniParser))。内部就是两个标准模型：

```
OmniParser V2
├── icon_detect    →  YOLOv8 (ultralytics 库加载)
│    └── 权重: weights/icon_detect/model.pt (~40MB)
│
└── icon_caption   →  Florence-2 base (transformers 加载)
     └── 权重: weights/icon_caption_florence/ (~0.5GB)
```

两个都可以直接 `import` 调用，不需要 Gradio 界面。

### 3.2 核心依赖

| 组件 | 库 | 大小 |
|------|-----|------|
| YOLOv8 检测 | `ultralytics` | ~20MB pip 包 |
| Florence-2 base 描述 | `transformers`（已有） | ~0.5GB 权重 |
| 总模型权重 | HuggingFace 下载 | ~0.6GB |

### 3.3 集成设计

```
不改的层:
  vision_server.py    FastAPI, POST /analyze  ← 协议不变
  vision_client.py    截屏+发送请求            ← 不变
  vision_debug_view.py 标注+可视化             ← 适配新 JSON 格式

替换的层:
  vision_model_v2.py  ─→ VisionModuleV2
    ├── YOLOv8 检测    → {boxes, confidences}
    ├── Florence-2 描述 → {captions}
    └── 合并输出       → 兼容旧 API 的 JSON

切换方式: vision_server.py 改一行 import
```

### 3.4 核心代码设计

```python
from ultralytics import YOLO
from transformers import AutoProcessor, AutoModelForCausalLM
from PIL import Image

class VisionModuleV2:
    def __init__(self):
        self.device = "cuda" if torch.cuda.is_available() else "cpu"
        # YOLO 检测器 — 快速定位 UI 元素
        self.detect_model = YOLO("models/OmniParser-v2.0/icon_detect/model.pt")
        # Florence-2 base — 为每个框生成功能描述
        self.caption_model = AutoModelForCausalLM.from_pretrained(
            "models/OmniParser-v2.0/icon_caption_florence",
            trust_remote_code=True
        ).to(self.device)
        self.caption_processor = AutoProcessor.from_pretrained(
            "models/OmniParser-v2.0/icon_caption_florence",
            trust_remote_code=True
        )

    async def analyze(self, image, task_prompt):
        # 1. YOLO 检测 → <0.5s
        results = self.detect_model(image)
        boxes = results[0].boxes.xyxy.cpu().tolist()
        confs = results[0].boxes.conf.cpu().tolist()

        # 2. Florence-2 为每个框生成描述
        labels = []
        for box in boxes:
            cropped = image.crop(tuple(box))
            caption = self._caption_crop(cropped)
            labels.append(caption)

        return {
            "boxes": boxes,
            "labels": labels,
            "confidences": confs
        }
```

### 3.5 已知风险

| 风险 | 应对 |
|------|------|
| YOLO 权重 AGPL-3.0 许可 | 个人使用无影响 |
| transformers 版本冲突（已遇到过） | 固定 `huggingface-hub<1.0` |
| 坐标格式差异 | YOLO 返回 `[x1,y1,x2,y2]`，统一转换 |
| HuggingFace 下载失败 | ModelScope 备选镜像 |
