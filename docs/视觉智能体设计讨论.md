# 视觉 Agent 设计讨论

> 日期：2026-07-13
> 状态：设计阶段

## 核心问题

视觉 Agent 需要理解桌面是三维结构映射到二维截图。窗口重叠、层次关系、元素归属——当前方案是平铺的 80 个框，没有窗口感知。

## 已识别问题

### P0
| 问题 | 方案方向 |
|------|---------|
| 窗口层次/元素归属 | 空间聚类 + 标题栏 OCR + 遮挡推断 |
| 元素状态(可点/不可点) | OD 标签里可能已有状态信息 |
| 阻断弹窗 | 弹窗特征：居中、遮罩、确认/取消按钮 |
| 时序判断/加载等待 | 连续截帧检测变化趋势 |

### P1
| 问题 | 说明 |
|------|------|
| 瞬时元素 | 右键菜单、下拉列表、tooltip |
| 输入焦点 | type()可能写进错的窗口 |
| 滚动盲区 | 内容在屏幕下方检测不到 |
| 窗口状态变化 | 最大化/最小化/多显示器 |

### P2
多步因果链——理解"上一步操作触发了什么状态变化"
