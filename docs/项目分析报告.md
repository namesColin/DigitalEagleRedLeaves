## 一、项目概述

**数字鹰红叶**是一个个人 AI 聊天机器人项目，目标是创建一个名为"红叶"（Hong Ye）的**数字生命体**。项目的核心理念不仅仅是做一个简单的 AI 助手，而是构建一个具备**记忆系统**、**视觉感知**和**个性化人格**的数字存在，最终形态为桌宠（通过 VTube Studio 呈现）。

---

## 二、技术栈

### 2.1 LLM 层

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| LLM 推理 | **Ollama** (本地部署) | 完全离线，无需云端 API |
| 主力模型 | **qwen3:8b** (5.2 GB) | 通义千问 3，8B 参数，中文能力强 |
| 备选模型 | deepseek-r1:8b / deepseek-r1:1.5b | DeepSeek R1 推理模型 |
| API 风格 | OpenAI-compatible (`/v1/chat/completions`) | 通过 Ollama 本地代理 |

### 2.2 记忆系统

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 知识图谱 | **Graphiti** (getzep/graphiti) | 开源 Python 库，神经元式图记忆 |
| 图数据库 | **Neo4j** (本地实例) | bolt://localhost:7687，存储实体与关系 |
| Embedding | **nomic-embed-text** (274 MB, 768维) | 文本向量化 |
| Reranker | **bge-reranker-v2-m3** (635 MB) | 搜索结果重排序 |

### 2.3 视觉模块

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 视觉模型 | **Microsoft Florence-2-large** (0.7B) | 本地部署，支持 OCR / 目标检测 / 画面描述 |
| 推理框架 | **Transformers + PyTorch + CUDA** | GPU 加速推理 |
| 通信架构 | **FastAPI** (C/S 微服务) | RESTful API，端口 30001 |

### 2.4 桌面工具

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| GUI 框架 | **PySide6** (Qt for Python) | 桌面监控小部件 |
| 屏幕截图 | **pyautogui + PIL** | 全屏截图 |
| GPU 监控 | **pynvml** (NVIDIA NVML) | GPU 利用率/温度/显存 |
| CPU/内存监控 | **psutil** | 系统资源监控 |
| 打包 | **PyInstaller** | 打包为独立 .exe |

## 五、数据流与交互流程

### 5.1 对话流程

```
用户输入 → memory.py (主循环)
  ├── personality.chat(question)
  │   ├── brain.search_memory(question) → Neo4j 图搜索
  │   ├── _build_prompt(context, question) → 构造红叶人格 Prompt
  │   └── llm_client.chat(prompt) → Ollama qwen3:8b 流式生成
  ├── 输出回答
  └── remember_dialogue(user_input + response)
      ├── check_semantic_exists() → 向量相似度去重
      └── brain.add_memory() → Graphiti 写入 Neo4j
```

### 5.2 视觉流程

```
vision_server.py (启动 FastAPI，加载 Florence-2 模型)
      ↑
vision_client.py / vision_debug_view.py
  ├── pyautogui.screenshot() → 全屏截图
  ├── requests.post("http://localhost:30001/analyze") → 上传图片
  └── 解析 JSON 结果 → 文字/坐标/描述
```

### 5.3 记忆导入流程

```
ingestMemory.py
  ├── 读取 .txt 文件（一行一条记忆）
  ├── 逐条 check_semantic_exists() → 语义去重
  └── brain.add_memory(source="Main-Brain") → 写入 Neo4j
```

## 六、技术亮点

1. **全本地部署**：LLM、Embedding、Reranker、视觉模型均本地运行，不依赖任何云端 API，隐私性强
2. **图记忆系统**：使用 Graphiti + Neo4j 实现类似人脑的神经元记忆网络，支持语义搜索和关系联想
3. **语义去重**：`check_semantic_exists()` 方法通过向量余弦相似度检测重复记忆，避免冗余
4. **微服务视觉架构**：视觉模块采用 C/S 分离设计，FastAPI 提供 RESTful API，可复用于不同项目
5. **流式对话**：LLM 响应采用 streaming 方式，提升用户体验
6. **桌面监控工具**：PySide6 实现的系统监控小部件，支持 GPU 监测和 Ollama 模型自动启动

## 八、总结

数字鹰红叶是一个**有明确愿景、架构清晰、核心模块基本完成**的个人 AI 项目。记忆系统和视觉系统已经可以正常工作，具备了作为数字生命的基础能力——**存储记忆**、**检索回忆**、**感知屏幕**和**个性对话**。

项目当前处于 **MVP 阶段**：大脑（记忆+语言）和眼睛（视觉）已就位，但手（指令执行）和脸（桌宠形象）尚未实现。技术选型务实且全本地化，适合个人开发者持续迭代。
